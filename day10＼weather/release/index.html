픽셀 웨더

픽셀 아트 스타일 날씨 검색 앱 · 스마트폰 홈 화면에 설치해서 쓸 수 있어요

☀️ 웹앱 열기
📲 설치 방법 (홈 화면에 추가)
아이폰 · Safari
  1. Safari로 위 “웹앱 열기” 버튼을 눌러 앱을 연다.
  2. 하단 공유 버튼(⬆️)을 누른다.
  3. “홈 화면에 추가”를 선택하면 아이콘이 생긴다.
안드로이드 · Chrome
  1. Chrome으로 위 “웹앱 열기” 버튼을 눌러 앱을 연다.
  2. 오른쪽 위 메뉴(⋮)를 누른다.
  3. “홈 화면에 추가” 또는 “앱 설치”를 선택한다.
PC · 크롬/엣지
  1. “웹앱 열기”로 접속한다.
  2. 주소창 오른쪽 설치(➕) 아이콘 또는 앱 안의 “홈 화면에 앱 설치” 버튼을 누른다.
📖 사용법
  1. 도시 이름을 입력한다 (예: Seoul, Busan, Tokyo).
  2. “검색” 버튼을 누른다.
  3. 현재 온도, 최고/최저, 풍향·풍속·습도가 표시된다.
