# 픽셀 웨더 - 배포용 폴더

`day10＼weather`에서 만든 픽셀 아트 날씨 검색 앱을 스마트폰에 설치해서 쓸 수 있는 형태로 묶은 배포용 폴더입니다.

## 폴더 구성
- `index.html` — 앱 다운로드/설치 안내 홈페이지. 여기서부터 시작하세요.
- `weather-app.html` — css/js가 모두 한 파일 안에 압축된 실제 앱(PWA) 본체.
- `README.md` — 이 문서.

## 사용법
1. `index.html`을 브라우저로 연다.
2. "☀️ 웹앱 열기" 버튼을 눌러 `weather-app.html`을 연다.
3. 도시 이름(예: Seoul)을 입력하고 검색 버튼을 누르면 날씨 정보가 표시된다.
4. 화면 아래 "홈 화면에 앱 설치" 버튼(설치가 가능한 브라우저에서만 표시됨)을 누르면 스마트폰 홈 화면에 아이콘으로 설치할 수 있다.

## 주소
- 로컬 파일: `release/index.html`, `release/weather-app.html`
- 온라인 주소: 아직 없음. GitHub Pages 등으로 배포하면 실제 https 주소가 생긴다.

## 주의사항
- 홈 화면 설치, 오프라인 캐싱(서비스워커)은 브라우저 보안 정책상 `file://`로 직접 열면 정상 동작하지 않을 수 있다.
- 실제 설치/오프라인 테스트를 하려면 로컬 서버(`npx serve` 등) 또는 GitHub Pages 같은 https 호스팅에서 열어야 한다.
- 날씨 데이터 자체는 실시간 API 호출이므로 오프라인일 때는 표시되지 않는다.
