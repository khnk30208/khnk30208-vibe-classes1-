
# 1. 프로그램 목적
- 기존 웹페이지(weather.html/css/js)로 만든 날씨 검색 사이트를 스마트폰에 "설치"해서 쓸 수 있는 앱(PWA, Progressive Web App)으로 전환한다.
- 최종 산출물은 css/js가 분리된 형태가 아니라, css와 js를 모두 하나의 html 파일 안에 압축(인라인)한 단일 파일 앱으로 배포한다.

# 2. 프로그램 설명
- 스마트폰 브라우저에서 "홈 화면에 추가"를 하면 아이콘이 생기고, 아이콘을 눌러 실행하면 주소창 없이 앱처럼 전체화면으로 열린다.
- 기존 데스크톱(웹)에서는 지금까지 만든 픽셀 카드 UI를 그대로 유지한다.
- 모바일 화면(폰 너비)에서는 카드가 화면 중앙에 떠 있는 형태가 아니라, 화면 전체를 채우는 앱 형태로 바뀐다.
- 기능(도시 검색, 날씨 표시, 풍향/풍속/습도)은 기존과 100% 동일하다. UI 껍데기와 설치 가능 여부만 달라진다.

# 3. 프로그램 기능
- 웹앱 매니페스트(manifest)를 통해 앱 이름, 아이콘, 테마 색상, 실행 방식(standalone)을 정의한다.
- iOS/Android 홈 화면 추가시 사용할 앱 아이콘을 제공한다 (기존 픽셀 디자인 톤에 맞춘 태양+구름 아이콘).
- 상태 표시줄(status bar) 색상을 앱 테마색(하늘색 계열)에 맞춘다.
- 서비스워커를 등록해 앱 껍데기(화면 구성)를 오프라인에서도 열 수 있도록 캐싱한다. (단, 실시간 날씨 데이터 자체는 인터넷 연결이 필요하다.)
- 브라우저가 설치를 지원하는 경우 "앱 설치" 버튼을 눌러 바로 설치할 수 있다. 지원하지 않으면 버튼은 표시되지 않는다.
- 화면 아래쪽 노치/제스처 바 영역과 겹치지 않도록 안전 영역(safe-area)을 확보한다.

# 4. 디자인
- 기존 weather.html/css의 픽셀 RPG 스타일(어두운 돌 패널, 청록/보라 네온, 픽셀 구름 배경)을 그대로 계승한다.
- PC처럼 화면이 넓을 때는 지금과 같이 가운데 떠 있는 카드 형태.
- 스마트폰처럼 화면이 좁을 때는 카드 테두리 여백이 사라지고, 패널이 화면 전체(높이 100%)를 채운다.
- 앱 아이콘은 어두운 돌 패널 배경 위에 픽셀 태양 + 구름을 그린 정사각형 아이콘.

# 5. 기술 스펙
- html 한 파일(weather-app.html) 안에 css(`<style>`)와 js(`<script>`)를 모두 인라인으로 포함해 "압축"한다. 외부 파일은 픽셀 폰트(Galmuri) CDN만 계속 사용한다.
- `<link rel="manifest">` 는 별도 .json 파일 없이 data URI로 매니페스트 내용을 직접 삽입한다.
- 서비스워커도 별도 .js 파일 없이, 인라인 스크립트 안에서 Blob으로 코드를 만들어 등록한다.
- 앱 아이콘은 base64 PNG data URI로 html 안에 내장한다 (외부 이미지 파일 없음).
- 기존 3파일 버전(weather.html/css/js)은 "웹" 버전으로 그대로 남겨두고, weather-app.html은 그 위에 추가되는 "설치형 앱" 버전이다.
- 주의: 브라우저 설치(홈 화면 추가)와 서비스워커는 `file://`로 직접 열면 정상 동작하지 않을 수 있다. 로컬 서버(예: `npx serve`)나 GitHub Pages 같은 https 호스팅에서 열어야 실제 설치 테스트가 가능하다.
