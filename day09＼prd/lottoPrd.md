

# 1. 프로그램 목적
- 로또 번호생성기를 만든다.

# 2. 프로그램 설명
- 로또는 1 ~ 50 사이에서 6개의 번호를 무작위로 뽑아준다.
- 각 번호는 중복되지 않는다.
- 뽑히는 번호는 순서 또는 크기에 상관없이 뽑힐 수 있다.
- 포함하는 번호 3개, 제외번호 3개를 선택할 수 있다.
- 번호 생성 버튼을 누르면 추천번호가 5개 생성된다.



# 3. 프로그램 기능
- 번호 추출은 랜덤함수를 이용하여 추출한다.
- 포함번호는 최대 3개, 불포함 번호는 최대 3개
- 포함번호는 반드시 로또 번호에 들어간다.
- 불포함번호는 반드시 로또 번호에서 제외한다.
- 각 번호는 색상을 가진다.
- 생성버튼을 누르면 5세트의 추첨번호가 발생한다.
- 초기화버튼을 누르면 모든 번호와 세팅이 초기화 된다.


# 4. 디자인
- 밝은 계통의 색상을 배경색으로 사용
- 각 번호는 공모양으로 색상을 부여
- 바탕색이 있고, 번호는 흰색으로 처리
- 최상단에는 로또 생성기 라고 제목 표시
- 그 밑에 포함번호와 불포함 번호 선택 영역을 나란히 둔다.
- 생성 버튼을 누르면 하단에 로또 번호가 5줄 생긴다.
- 생성 버튼과 초기화 버튼은 같은 라인에 표시
- 생성 버튼을 누르면 3초 정도 효과음 출력과 함께 번호 생성
- 효과음은 긴장감있는 소리로 만들어 주세요.
 

# 5. 기술 스펙
- html/cs/js 만 가지고 웹페이지 형식으로 만드세요.
- 외부 라이브러리 사용 금지
- css는 별도 파일로 만들어서 링크 처리
- js 도 별도 파일로 만들어서 링크 처리
