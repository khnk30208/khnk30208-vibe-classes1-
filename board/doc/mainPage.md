> 작성일: 2026-08-06
> 대상 프로젝트: `board/`
> 선행 문서: `doc/header-menu.md`


# 1. 요청 원문

```
Home을 누르면 이동하고, 맨처음 보여줄 대문 페이지를 만들자.

대문페이지는 openWeatherAPI를 이용해서 서울과 도쿄의 현재 시간, 현재 날씨,
현재 온도를 간단하게 대시보드 형태로 출력해줘.

KEY는 .env 파일을 만들어서 저장하고, 입력은 개발자가 하도록 해줘.

배경은 연두색 계열록으로 하고. 카드는 약간 음영을 줘서 게임 픽셀 스타일로 디자인 해줘.
```


# 2. 요구사항

## 2.1 진입 / 이동

- 앱을 열면 **대문 페이지가 맨 처음** 보인다 (`DEFAULT_MENU_KEY = 'home'`)
- 헤더의 `Home` 로고를 누르면 대문 페이지로 돌아온다
- 이동이라고 해서 주소가 바뀌는 것이 아니다.
  `CLAUDE.md` 3. 레이아웃 구조대로 `MainLayout` 의 컨텐츠 영역만 교체한다

## 2.2 표시 항목

서울 / 도쿄 두 도시를 카드 2장으로 나란히 보여준다.

| 항목 | 출처 |
|---|---|
| 도시명 | `constants/cities.js` (로마자 `latin` + 한글 `label`) |
| 현재 시간 | `Intl.DateTimeFormat` + `timeZone` (`Asia/Seoul`, `Asia/Tokyo`), 1초마다 갱신 |
| 현재 날씨 | OpenWeather 응답의 `weather[0].description` + `weather[0].icon` |
| 현재 온도 | OpenWeather 응답의 `main.temp` (섭씨, 소수 1자리) |

- 날짜도 함께 보여준다 (시간만 있으면 어느 날인지 알 수 없다)
- 시간은 `AM/PM`, `시:분`, `초` 세 조각으로 나눠 받는다 (`formatTimeParts`).
  화면에서 크기를 다르게 주기 위한 것이다

## 2.3 API

- **OpenWeatherMap 현재 날씨 API 를 쓴다** (기존 Open-Meteo 는 걷어낸다)
- `https://api.openweathermap.org/data/2.5/weather`
- 파라미터: `q`(도시), `appid`(키), `units=metric`, `lang=kr`
- 도시 질의값: 서울 `Seoul,KR` / 도쿄 `Tokyo,JP`

## 2.4 API 키 관리 (중요)

- 키는 `.env` 의 `VITE_OPENWEATHER_API_KEY` 로 읽는다
- **키 값은 개발자가 직접 입력한다.** 에이전트는 빈 값의 `.env` 만 만들어 둔다
- `.env` 는 `.gitignore` 에 넣어 커밋되지 않게 한다.
  형식만 공유하도록 `.env.example` 을 함께 둔다
- 키가 비어 있으면 API 를 호출하지 않고,
  카드에 "`.env` 에 `VITE_OPENWEATHER_API_KEY` 를 입력해 주세요." 안내를 띄운다
  (키가 없어도 도시명 / 날짜 / 시간은 정상 동작해야 한다)
- 키를 넣은 뒤에는 **개발 서버를 재시작**해야 반영된다 (Vite 는 `.env` 를 빌드 시점에 읽는다)


# 3. 디자인

> **개정 이력** — 처음에는 게임 픽셀 스타일이었다.
> "고급스러운 브랜드 사이트 느낌 / 연하고 채도가 낮은 연두색 그라데이션 /
> 글자 디자인" 요청으로 아래 방향으로 **전면 교체**했다.
> 픽셀 스타일(굵은 테두리, 계단식 그림자, 등폭 폰트)은 더 이상 쓰지 않는다.

## 3.1 컨셉

**"같은 시각, 다른 하늘."**

서울과 도쿄는 둘 다 UTC+9 라 **시각이 늘 같다.** 다른 것은 하늘뿐이다.
이 사실을 화면 구조로 그대로 옮긴다.

- 카드 두 장을 따로 놓지 않는다. **한 장의 판을 실선 하나로 가른 형태**(딥틱)로 만든다
- 머리말이 이 사실을 문장으로 말하고, 눈금(`UTC+09:00 · 같은 시간대`)이 근거를 댄다
- 장식용 구분선·번호 매기기는 넣지 않는다. 선은 두 도시를 가르는 그 한 줄뿐이다

## 3.2 색

바탕은 **연하고 채도가 낮은 연두색**이다. 단색 그라데이션 하나로 끝내지 않고,
흰 빛과 연두 빛 두 겹을 얹어 깊이를 만든다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--canvas-top` | `#f4f6f0` | 바탕 위쪽 (거의 흰 연두) |
| `--canvas-mid` | `#e7eddf` | 바탕 가운데 |
| `--canvas-bottom` | `#d8e1cb` | 바탕 아래쪽 |
| `--ink` | `#212619` | 본문 먹색 (초록 기미가 있는 검정) |
| `--ink-soft` | `#626b57` | 보조 텍스트 |
| `--ink-faint` | `#8d9680` | 눈금·라벨 |
| `--hairline` | `rgb(33 38 25 / 14%)` | 실선 |

- 바탕은 `MainLayout` 의 `.layout` 이 갖는다. **앱 전체가 같은 바탕을 공유**한다
- **강조색을 따로 두지 않는다.** 파랑·빨강 버튼 같은 원색은 쓰지 않고,
  먹색과 바탕색의 명도 차이만으로 위계를 만든다
- 판은 `rgb(255 255 255 / 52%)` 반투명 흰색이라 바탕 그라데이션이 비쳐 보인다
- 그림자는 번지고 깊게 깐다 — `0 32px 60px -40px rgb(33 38 25 / 45%)`.
  거의 안 보이지만 판이 떠 있는 느낌을 만든다

## 3.3 글자 (중요)

두 벌만 쓴다. 웹폰트는 받지 않는다 (한글 글리프 문제 + 외부 의존).

| 역할 | 폰트 | 쓰는 곳 |
|---|---|---|
| 본문·제목 | 고딕 (`Malgun Gothic` 계열) | 한글 전부, 메뉴, 라벨 |
| 숫자 | **세리프** (`Palatino Linotype` 계열) | 시간, 기온 **딱 두 곳** |

**시계를 세리프로 짜는 것**이 이 화면의 성격이다.
시계는 보통 등폭·디지털 서체로 짜는데, 그 반대로 가서 브랜드 사이트의 인상을 만든다.
세리프는 여기 말고 다른 데 쓰지 않는다.

한글은 **굵게 쓰지 않는다.** 무게를 300 으로 낮추고 자간을 좁혀(`-0.025em`)
큰 크기에서 우아하게 보이도록 한다.

| 요소 | 크기 | 무게 | 자간 |
|---|---|---|---|
| 눈금(eyebrow) | `11px` 대문자 | 500 | `0.3em` |
| 표제 | `clamp(34px, 5.4vw, 58px)` | 300 | `-0.025em` |
| 도시 로마자 | `10px` 대문자 | 500 | `0.34em` |
| 도시 한글 | `22px` | 300 | `-0.01em` |
| 시·분 | `clamp(40px, 6vw, 58px)` 세리프 | 400 | `-0.01em` |
| AM/PM | `11px` | 500 | `0.18em` |
| 초 | `clamp(15px, 1.8vw, 19px)` 세리프 | 400 | — |
| 날짜 | `12px` | 400 | `0.14em` |
| 기온 | `clamp(32px, 4.4vw, 44px)` 세리프 | 400 | `-0.015em` |
| 날씨 설명 | `12px` | 400 | `0.14em` |

- **초는 작게 눌러** 시·분에 시선이 먼저 가게 한다. 숫자는 `tabular-nums` 로 고정폭
- 작은 글자는 자간을 넓히고(`0.14em`~`0.34em`), 큰 글자는 좁힌다(`-0.01em`~`-0.025em`).
  이 대비가 "글자 디자인"의 핵심이다

## 3.4 날씨 아이콘

- OpenWeatherMap 이 주는 PNG 아이콘은 **쓰지 않는다.** 만화풍이라 톤이 깨진다
- `components/WeatherGlyph.jsx` 에서 **선으로 직접 그린다**
  (`stroke-width: 1.4`, `currentColor`, 둥근 끝처리)
- 응답의 아이콘 코드(`01d`, `10n` …)를 받아 해·달·구름·비·눈·번개·안개로 매핑한다
- `service` 는 `iconUrl` 이 아니라 `iconCode` 만 넘긴다. 그리는 것은 화면 몫이다

## 3.5 헤더 / 푸터

- `doc/header-menu.md` 5. 의 값(높이 `56px`, 회색 그라데이션, 흰색 `20px` 고딕)은 유지한다
- 다만 회색을 **초록 기미가 있는 회색**(`#5e655a` → `#2f342b`)으로 골라
  연두색 바탕과 같은 계열에 놓는다
- 메뉴 글자 무게를 300 으로 낮추고, `Home` 로고는 자간을 `0.22em` 벌려
  메뉴와 성격을 구분한다

## 3.6 배치

```
UTC+09:00 · 같은 시간대          ← 눈금
같은 시각,
다른 하늘.                       ← 표제

┌─────────────────┬─────────────────┐
│ SEOUL           │ TOKYO           │
│ 서울            │ 도쿄             │
│                 │                 │
│ PM 09:34 19     │ PM 09:34 19     │
│ 2026.08.06 목   │ 2026.08.06 목   │
│ ─────────────   │ ─────────────   │
│ ☁  29.4°        │ ☀  26.7°        │
│    구름 조금     │    맑음          │
└─────────────────┴─────────────────┘
                  ↑ 두 판을 가르는 실선 하나
```

- 좁은 화면(680px 이하)에서는 세로 1열이 되고, 가르는 선이 위쪽 테두리로 바뀐다
- 판 전체 최대 폭 `880px`, 화면 가운데 정렬

## 3.7 동작

- 로드 시 머리말 → 딥틱 순서로 12px 아래에서 올라오며 나타난다 (0.8s, 0.12s 시차)
- 그 외 애니메이션은 넣지 않는다. 초가 매초 바뀌는 것만으로 충분히 살아 있다
- `prefers-reduced-motion: reduce` 면 등장 동작을 끈다
- 키보드 포커스는 `:focus-visible` 로 항상 보이게 한다


# 4. 파일 계획

## 4.1 새로 만드는 파일

```
board/
  .env                           VITE_OPENWEATHER_API_KEY=   (빈 값, 커밋 안 함)
  .env.example                   형식 공유용
  doc/mainPage.md                이 문서
```

## 4.2 고치는 파일

| 파일 | 변경 |
|---|---|
| `src/api/weatherApi.js` | Open-Meteo → OpenWeatherMap 호출로 교체 |
| `src/service/weatherService.js` | 날씨 설명 + `iconCode` 반환, 키 없음 / 401 / 404 상태 처리 |
| `src/constants/cities.js` | OpenWeather 질의값(`query`) + 로마자 표기(`latin`) |
| `src/components/WeatherGlyph.jsx` | **신규** — 날씨 아이콘을 선으로 직접 그린다 |
| `src/utils/datetime.js` | `formatTimeParts` 추가 (AM/PM · 시:분 · 초 분리) |
| `src/pages/HomePage.jsx` | 딥틱 구조로 재작성 |
| `src/pages/HomePage.module.css` | 브랜드 톤으로 전면 교체 |
| `src/layouts/MainLayout.module.css` | 연두색 그라데이션 바탕을 앱 전체에 적용 |
| `src/index.css` | 색·폰트 토큰 정의, `:focus-visible` |
| `src/components/Header.module.css` | 회색을 초록 기미 회색으로, 글자 무게·자간 조정 |
| `src/components/Footer.module.css` | 헤더와 동일 |
| `src/components/UserMenu.module.css` | 드롭다운을 같은 팔레트로 |
| `src/pages/AuthPage.module.css` | 원색 버튼 제거, 밑줄 입력 + 먹색 버튼 |
| `src/pages/PlaceholderPage.module.css` | 토큰 사용 |
| `.gitignore` | `.env` 추가 |

- 레이어 규칙은 그대로다: `pages` → `service` → `api`.
  `HomePage` 는 `weatherApi` 를 직접 import 하지 않는다


# 5. 상태별 화면

| 상태 | 카드 표시 |
|---|---|
| 키 없음 | 날짜·시간은 정상, 날씨 자리에 `.env` 안내 |
| 조회 중 | 날씨 자리에 `불러오는 중…` |
| 성공 | 아이콘 + 날씨 설명 + 온도 |
| 실패 | 날씨 자리에 실패 문구 (401 이면 "API 키를 확인해 주세요.") |

- 한 도시가 실패해도 다른 도시는 정상 표시한다 (`Promise.allSettled`)


# 6. 완료 조건

- 앱 최초 화면이 대문 페이지다
- 다른 메뉴로 갔다가 `Home` 을 누르면 대문 페이지로 돌아온다 (주소 변경 없음)
- 바탕이 연하고 채도가 낮은 연두색 그라데이션이다
- 두 도시가 실선 하나로 갈린 한 장의 판으로 보인다 (카드 두 장이 아니다)
- 시간과 기온만 세리프이고, 나머지 한글은 가벼운 고딕이다
- 서울 / 도쿄의 날짜·시간이 1초마다 갱신되고, 초가 시·분보다 작다
- `.env` 에 키를 넣고 재시작하면 날씨 글리프·설명·기온이 표시된다
- 키가 없을 때 안내 문구가 보이고 화면이 깨지지 않는다
- 680px 이하에서 세로 1열이 되고 가로 스크롤이 생기지 않는다
- `npm run lint` 와 `npm run build` 통과
