
# CALUDE.md
- 해당 문서의 내용을 반드시 지킬 것
- 문서의 내용을 무시하거나 실행하지 않으면 안됨
- 모든 작업은 한글로 소통하고 작성한다.


# 1. 기술 스택
- 개발에 필요한 라이브러리는 설치할 것

## 1.1 사용 언어
- react with javascrips 사용

## 1.2 빌드 도구
- vite

## 1.3 CSS 처리
- 기본적으로 css module 사용
- Tailwind css 최신버전 사용

## 1.4 서버 통신
- axios 를 이용한 서버 통신

# 2. 폴더 구조
- `pges` : view 컴포넌트
- `service` : 비지니스 로직
- `api` : 서버 통신 모듈


# 3. 작업 규칙
- 요청한 내용 외 임의 판단 금지
- 에이전트 임의 판단으로 인한 코드 작성 금지
- 이미 작성된 코드의 수정을 최소화
- 수정이 필요할 경우 반드시 물어 볼 것
