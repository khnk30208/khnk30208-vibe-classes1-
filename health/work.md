## 2. 기능 범위

### 2.1 입력

- 필수: 성별, 나이, 신장(cm), 체중(kg)
- 선택: 활동량, 목표 체중, 체지방률, 골격근량, 내장지방 레벨
- 선택: 혈액검사 수치 (공복혈당, 총콜레스테롤, LDL, HDL, 중성지방, 헤모글로빈)
- 파일 첨부: 인바디 결과지 / 혈액검사 결과지 (이미지 · PDF)

### 2.2 분석 항목

| 코드 | 항목 | 계산 방식 |
|---|---|---|
| H-1 | BMI · 표준체중 · 비만도 | BMI = 체중(kg) / 신장(m)² |
| H-2 | 기초대사량(BMR) · 활동대사량(TDEE) · 권장 칼로리 | Mifflin-St Jeor |
| H-3 | 인바디 지표 평가 (체지방률·골격근량·내장지방) | 성별 기준표 대조 |
| H-4 | 혈액검사 해석 | 일반 참고 기준치 대조 |
| H-5 | 목표 체중 도달 기간 시뮬레이션 | 체지방 1kg ≈ 7,700kcal |
| H-6 | 부족 영양소 추정 + 음식 추천 | 판정 결과 → 영양소 매핑 |
| H-7 | 운동 추천 (부위별 · 강도별) | 판정 결과 → 운동 매핑 |

### 2.3 계산식 (service 레이어에 둔다)

**BMI 판정 (대한비만학회 기준)**

| 범위 | 판정 |
|---|---|
| < 18.5 | 저체중 |
| 18.5 ~ 22.9 | 정상 |
| 23.0 ~ 24.9 | 과체중 |
| 25.0 ~ 29.9 | 비만 1단계 |
| 30.0 ~ 34.9 | 비만 2단계 |
| ≥ 35.0 | 비만 3단계 |

**표준체중**
- 남성: 신장(m)² × 22
- 여성: 신장(m)² × 21

**기초대사량 (Mifflin-St Jeor)**
- 남성: `10 × 체중(kg) + 6.25 × 신장(cm) − 5 × 나이 + 5`
- 여성: `10 × 체중(kg) + 6.25 × 신장(cm) − 5 × 나이 − 161`

**활동대사량 (TDEE) = BMR × 활동계수**

| 활동량 | 계수 |
|---|---|
| 거의 안 움직임 | 1.2 |
| 가벼운 활동 (주 1~3회) | 1.375 |
| 보통 활동 (주 3~5회) | 1.55 |
| 활발한 활동 (주 6~7회) | 1.725 |
| 매우 활발 (육체노동·2회 운동) | 1.9 |

**체지방률 참고 범위**
- 남성 15~20% / 여성 20~28%

**혈액검사 참고 기준치** — 진단 기준이 아니라 **참고용**이다

| 항목 | 참고 범위 |
|---|---|
| 공복혈당 | 70 ~ 99 mg/dL (100~125 주의, 126 이상 상담 권고) |
| 총콜레스테롤 | 200 mg/dL 미만 |
| LDL | 130 mg/dL 미만 |
| HDL | 남 40 이상 / 여 50 이상 |
| 중성지방 | 150 mg/dL 미만 |
| 헤모글로빈 | 남 13~17 / 여 12~16 g/dL |

**목표 체중 도달 기간**
- 체지방 1kg 감량 ≈ 7,700kcal 적자
- 하루 적자 kcal 를 입력받아 `필요일수 = (감량목표kg × 7700) / 하루적자` 로 계산
- 주당 0.5~1kg 이내 감량을 권장 범위로 안내한다

### 2.4 파일 첨부 분석 (단계 4)

- **Tesseract.js 로 브라우저 안에서만** OCR 한다. 외부 서버 업로드 금지
- 인바디 결과지는 기기 모델(270/570/970)마다 레이아웃이 달라 100% 인식은 불가능하다.
  따라서 **OCR 결과로 입력 폼을 자동 채우고, 사용자가 확인·수정하는 방식**으로 만든다
- 인식 실패 시 에러로 막지 않고 수동 입력으로 자연스럽게 넘어가게 한다

### 2.5 영양소 · 음식 추천 (단계 5)

- 판정 결과 → 부족 추정 영양소 → 해당 영양소가 풍부한 음식 목록
- 데이터는 `src/assets/` 의 로컬 JSON 으로 큐레이션한다 (무료·무제한·오프라인)
- 식약처 식품영양성분 DB OpenAPI 는 "음식 직접 검색" 기능에만 보조로 쓴다

### 2.6 헬스장찾기 (단계 6)

- 위치: 브라우저 Geolocation API 우선 → 거부·실패 시 IP 기반 위치로 폴백
  → 그것도 안 되면 지역 직접 선택
- 검색·지도: 카카오맵 JavaScript SDK 키워드 검색 (`헬스장`) + 반경 필터
- 표시 항목: 이름, 거리, 주소, 전화번호, 지도 마커
- 카카오 JavaScript 키는 `.env` 의 `VITE_KAKAO_MAP_KEY` 로 읽는다.
  키가 없으면 화면이 깨지지 않고 안내 문구를 보여준다

### 2.7 내기록 (단계 7)

- 분석 결과를 localStorage 에 날짜별로 저장
- 체중·체지방률 변화 추이를 Recharts 로 그래프 표시
- 기록 삭제·초기화 기능 제공


## 3. 화면 구성

- 모든 화면은 `MainLayout` 안에서 그려진다. 메뉴를 눌러도 페이지 이동이 없다
  (자세한 규칙은 `CLAUDE.md` 4장)
- 메뉴: 게시판 / 건강분석 / 헬스장찾기 / 내기록
- 기본 화면: 게시판


## 4. 저장

- 백엔드 서버 없음. 전부 localStorage
- 게시판 글, 건강 기록 모두 클라이언트에만 저장된다
- 사용자에게 "이 브라우저에만 저장됩니다" 를 안내한다


## 5. 지켜야 할 것

- 분석 결과는 **의학적 진단이 아니다.** 결과 화면마다 면책 문구를 노출한다
- 혈액검사·인바디 등 민감 정보는 브라우저 밖으로 내보내지 않는다
- 유료 API·백엔드 서버를 임의로 추가하지 않는다

자세한 규칙은 `CLAUDE.md` 5장 참고.
