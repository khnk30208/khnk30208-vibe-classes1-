# 2. 해석 및 결정 사항

## 2.1 어디에 붙이는가

- 메인 대시보드의 **`건강` 카드**가 진입점이다 (`CLAUDE.md` 4.4)
- `HomePage` 가 `view`(`'dashboard' | 'input'`) 상태를 갖는다
  - `'dashboard'` : 카드 5장. `건강` 카드에 분석 결과 요약
  - `'input'` : 입력 폼 전체 화면
- 분석 전에는 `건강` 카드에 **[건강정보 입력하기]** 버튼,
  분석 후에는 결과 + **[다시 입력]** 버튼
- 결과가 있으면 `건강` 카드는 격자에서 **전체 너비로 확장**한다 (표시할 값이 많다)

## 2.2 카드는 5장을 유지한다

- 사용자가 지정한 대시보드 구성(건강 / 필요한 영양소 / 음식 추천 / 생활 습관 팁 /
  주변 헬스장)을 바꾸지 않는다
- 따라서 **혈액검사 해석도 `건강` 카드 안의 하위 영역**으로 넣는다. 카드를 늘리지 않는다

## 2.3 저장하지 않는다

- 이번 단계는 **입력 → 계산 → 표시**까지다
- 기록 저장·추이 그래프는 `work.md` 단계 7(내기록)이다. 여기서 localStorage 를 쓰지 않는다
- 즉 새로고침하면 분석 결과는 사라진다. 의도된 동작이다

## 2.4 입력 항목

| 구분 | 항목 | 필수 | 비고 |
|---|---|---|---|
| 기본 | 성별 | ✅ | 남 / 여 |
| 기본 | 나이 | ✅ | 1~120 |
| 기본 | 신장(cm) | ✅ | 50~250 |
| 기본 | 체중(kg) | ✅ | 10~300 |
| 기본 | 활동량 | ✅ | 기본값 "보통 활동" |
| 목표 | 목표 체중(kg) | — | 비우면 목표 항목 생략 |
| 목표 | 하루 칼로리 적자 | — | 기본 500kcal |
| 인바디 | 체지방률(%) | — | 비우면 평가 생략 |
| 혈액 | 공복혈당 / 총콜레스테롤 / LDL / HDL / 중성지방 / 헤모글로빈 | — | 입력한 항목만 해석 |

- 선택 항목은 **비어 있으면 그 결과만 생략**한다. 에러로 막지 않는다

## 2.5 계산식 (work.md 2.3 그대로)

- **BMI** = 체중(kg) / 신장(m)²
- **BMI 판정** (대한비만학회): `<18.5` 저체중 / `18.5~22.9` 정상 / `23~24.9` 과체중 /
  `25~29.9` 비만 1단계 / `30~34.9` 비만 2단계 / `≥35` 비만 3단계
- **표준체중** = 신장(m)² × 22(남) 또는 21(여)
- **BMR (Mifflin-St Jeor)**
  - 남: `10×체중 + 6.25×신장(cm) − 5×나이 + 5`
  - 여: `10×체중 + 6.25×신장(cm) − 5×나이 − 161`
- **TDEE** = BMR × 활동계수 (1.2 / 1.375 / 1.55 / 1.725 / 1.9)
- **체지방률 참고**: 남 15~20% / 여 20~28%
- **목표 기간** = `(감량목표kg × 7700) / 하루적자kcal` 일
  - 주당 0.5~1kg 을 권장 범위로 함께 안내한다

## 2.6 계산에서 반드시 막아야 할 것 (에러 방지)

- 신장 0 → 0 나누기 (`Infinity` / `NaN`) 방지: 필수값은 범위 검사를 통과해야 계산에 들어간다
- 빈 문자열을 `Number('')` 하면 `0` 이 된다. **빈 값은 `null` 로 정규화**한 뒤 판단한다
- 목표 체중이 현재 체중 **이상**이면 감량 기간을 계산하지 않는다 (유지/증량 안내)
- 하루 적자가 0 이하면 계산하지 않는다
- 표시 직전에 `Number.isFinite` 로 한 번 더 거른다

## 2.7 의료 면책

- 결과 화면에 면책 문구를 노출한다 (`CLAUDE.md` 5장). 이미 대시보드 하단에 있다
- 혈액검사 해석 문구는 **"정상 범위" / "참고 범위를 벗어남 — 상담 권고"** 수준까지만 쓴다.
  특정 질병을 단정하지 않는다

# 4. 완료 조건

- `건강` 카드의 [건강정보 입력하기] → 입력 폼으로 전환 (주소 불변)
- 필수값을 비우고 제출하면 에러 메시지가 뜨고 계산되지 않는다
- 정상 입력 시 BMI·판정·표준체중·BMR·TDEE 가 표시된다
- 목표 체중을 넣으면 도달 기간이, 비우면 해당 항목이 표시되지 않는다
- 체지방률·혈액검사를 넣으면 평가가 추가되고, 비우면 생략된다
- 화면 어디에도 `NaN` / `Infinity` / `undefined` 가 보이지 않는다
- 면책 문구가 보인다
- 콘솔 에러 0건, `npm run lint` 통과
