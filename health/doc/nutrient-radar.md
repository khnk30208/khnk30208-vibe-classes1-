# nutrient-radar.md

> 필요한 영양소 — 오각형 레이더 + 순회 재생 작업 프롬프트
> 작성일: 2026-08-08
> 대상 프로젝트: `health/`
> 참고 자료: 사용자 제공 `AI드라마_컷분석.html` 의 "컷 리듬"


# 1. 요청 원문

```
영양소 추천을 오각형이나 육각형으로 (단백질,탄수화물,지방,..) 이런식으로
인간의 중요한 영양소를 중요도 순으로 결과 나오게 진행해줘.
오각형 그래프를 오른쪽으로 배치하고 왼쪽에는 영양소를 추천하는 이유,
추천 음식 메뉴등을 적을 수 있는 기능으로 진행해줘.
내가 참고로 보낸 html에서 움직이는 그래프 처럼 재미 요소를 넣어줘.
```


# 2. 결정 사항 (사용자 확정)

| 항목 | 결정 |
|---|---|
| 차트 | **오각형 — 5대 영양소** (탄수화물·단백질·지방·비타민·무기질) |
| 꼭지점 값 | **보충 우선순위 0~100** |
| 움직임 | **자동 순회 재생** (LIVE 뱃지 + 타이머 + 재생/일시정지) |
| 배치 | 왼쪽 = 이유·세부 영양소·음식 / 오른쪽 = 오각형 |

## 2.1 점수의 의미 — 반드시 지킨다

- 이 점수는 **"측정된 결핍"이 아니다.** "지금 신경 쓸 우선순위"다
- 이 앱은 식사 기록을 받지 않는다. **섭취량을 추정하지 않는다.**
  권장량 대비 몇 % 같은 표현을 쓰지 않는다
- 점수가 올라간 **근거를 화면에 항상 함께 보여 준다**
  (어떤 검사 수치·체형 때문인지)
- 특정 질병을 단정하지 않는다 (`CLAUDE.md` 5장)

## 2.2 규칙을 새로 만들지 않는다

`service/nutritionService.js` 의 `recommendNutrients()` 가 이미
혈액검사 `kind`/`status`, `bmiTone`, `bodyFat`, `age` 를 근거로 영양소를 고르고
**이유 문자열까지 만들어 둔다.** 이번 작업은 그 결과를 **군(群) 단위로 접기만** 한다.
판정 기준이 두 곳에 갈라지면 나중에 반드시 어긋난다.


# 3. 점수 계산

## 3.1 영양소 → 군 매핑

| 군 | 속하는 세부 영양소 |
|---|---|
| 탄수화물 | 식이섬유 |
| 단백질 | 단백질 |
| 지방 | 오메가-3 지방산 |
| 비타민 | 비타민 B12, 엽산, 비타민 D |
| 무기질 | 철분, 마그네슘, 칼륨, 칼슘 |

## 3.2 산식

```
점수 = BASE_SCORE(30)
     + (그 군에 걸린 세부 영양소 1개당 +18)
     + (그 군에 걸린 서로 다른 이유 1개당 +9)
결과를 0~100 으로 클램프
```

- 기본선 30점을 두는 이유: 0점이 생기면 오각형이 찌그러진 별처럼 보여
  "이 영양소는 필요 없다" 는 잘못된 인상을 준다. 5대 영양소는 모두 필요하다
- 같은 이유가 여러 번 걸려도 한 번만 센다
- 아무 규칙에도 걸리지 않으면 전 군이 기본선 → "특별히 급한 항목 없음" 으로 표시

## 3.3 정렬

점수 내림차순. 동점이면 `NUTRIENT_GROUPS` 배열 순서를 따른다(정렬이 흔들리지 않게).


# 4. 순회 재생 (참고 HTML 컷 리듬)

`AI드라마_컷분석.html` 360~445행 / 1852행~ 의 구조를 따른다.

| 요소 | 동작 |
|---|---|
| 상단 진행 막대 | 현재 군의 진행률을 `--beat` 로 `scaleX(0~1)` |
| `LIVE` 뱃지 | 점이 `blink 1.1s steps(1,end) infinite` 로 깜빡임 |
| 타이머 | 모노폰트 `0:05` 형식, 재생 경과 시간 |
| 재생/일시정지 | `data-state="playing｜paused"` 로 아이콘 교체 |
| 순회 | `STEP_MS`(2400ms) 마다 다음 군. 끝나면 처음으로 |

## 4.1 멈춰야 하는 경우

- **화면 밖**: IntersectionObserver 로 감지해 rAF 중단 (배터리)
- **탭 숨김**: `visibilitychange` 로 중단
- **`prefers-reduced-motion: reduce`**: 자동 재생을 시작하지 않는다.
  1순위 군을 정지 상태로 보여 주고, 사용자가 원하면 재생 버튼을 누를 수 있게 둔다


# 5. 파일 계획

```
src/
  constants/
    nutrientGroups.js        5대 영양소군 정의 + 점수 상수
  assets/
    nutrients.json           각 항목에 group 키 추가
  service/
    nutritionService.js      scoreNutrientGroups() 추가 (기존 함수는 유지)
  components/
    NutrientRadar.jsx        오각형 SVG (표현만)
    NutrientRadar.module.css
    NutrientPriority.jsx     재생 상태 + 좌우 2단 배치
    NutrientPriority.module.css
  pages/
    HomePage.jsx             영양소 카드가 NutrientPriority 를 렌더
```

- `service` 는 React 를 import 하지 않는다
- 차트 라이브러리를 새로 설치하지 않는다. 인라인 SVG 로 그린다


# 6. 표현 규칙

- 그래프에만 값을 두지 않는다. **축 라벨에 점수를 숫자로 병기**한다
  (`doc/design-system.md` 6장 — 색각 이상·스크린리더 대응)
- 레이더 전체에 `role="img"` 와 순위를 문장으로 담은 `aria-label` 을 준다
- 조명 강조에는 `--pulse` 를 쓴다. 데이터 색이 아니라 "현재 위치" 신호다


# 7. 완료 조건

- 분석 후 영양소 카드가 좌(설명)/우(오각형) 2단으로 보인다
- 오각형이 중심에서 펴지며 그려지고, 조명된 꼭지점이 커진다
- 타이머가 흐르고 2.4초마다 다음 군으로 넘어간다
- 일시정지를 누르면 멈추고, 다시 누르면 이어서 재생된다
- 화면 밖으로 스크롤하면 타이머가 멈춘다
- `prefers-reduced-motion` 에서 자동 재생이 시작되지 않고 1순위 군이 보인다
- 375px 에서 1열로 접히고 가로 스크롤이 없다
- 점수가 0~100 안이고 화면에 `NaN` 이 없다
- 라이트/다크 정상, 콘솔 에러 0건, `npm run lint` · `npm run build` 통과
