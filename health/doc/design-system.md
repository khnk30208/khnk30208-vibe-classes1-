# 1. 요청

```
해당 디자인을 내가 첨부한 html처럼 디자인과 툴, 움직이는 모션, 건강 결과를
알맞게 진행해줘. 전체적인 색감과 폰트 스타일, 그리고 해당 html에 움직이는
그래프나 다양한 모션등을 구상해서 웹에 스타일 폰트를 알맞게 설정 진행해줘.

오래 걸려도 좋으니 요즘 사이트의 폰트 UI 수준과 거의 맞먹는 수준으로 진행해줘.
```


# 2. 참고 HTML 에서 가져오는 것

| 요소 | 내용 |
|---|---|
| 폰트 | **Pretendard Variable** (한국어 UI 표준). 숫자는 `tabular-nums` 고정폭 |
| 색 체계 | 표면(plane/panel) · 잉크(ink 3단계) · 선(line/track) 을 토큰으로 분리 |
| 색감 | 아주 연한 하늘빛 배경 + 남색 잉크 + 파랑 계열 시리즈 색 |
| 강조색 | **난색 1개만** 사용. 데이터가 아니라 "움직임·현재 위치" 신호 전용 |
| 다크 모드 | `prefers-color-scheme` + `data-theme` 수동 토글 양쪽 지원 |
| 모션 | 스크롤 진입 시 `reveal`, 막대 `width` 성장, 숫자 카운트업, 순차 지연 |
| 접근성 | `prefers-reduced-motion` 에서 전 모션 무력화, 포커스 링, `sr-only` |
| 그림자 | 3단계(`sh-1/2/3`), hover 시 상승 |

## 2.1 그대로 베끼지 않는 것

- 참고 HTML 은 **리포트 문서**, 이 프로젝트는 **앱**이다. 스크롤 진행 막대·섹션
  내비게이션·본문 리드 같은 문서 전용 장치는 가져오지 않는다
- 시리즈 색(작품 구분용)은 **건강 의미 색**(정상/주의/이탈)으로 바꾼다

## 2.2 헤더 디자인 변경 (중요)

- `doc/header-menu.md` 5장에서 헤더는 **회색 그라데이션**이었다
- 이번 요청이 "전체적인 색감"을 참고 HTML 기준으로 맞추라는 것이므로,
  연한 하늘빛 배경 위에 짙은 회색 바가 놓이면 톤이 깨진다
- 따라서 헤더를 참고 HTML 의 상단 바처럼 **반투명 + 블러 + 하단 헤어라인**으로 바꾼다
- **높이 56px, 메뉴 20px 고딕은 그대로 유지**한다
- 회색 그라데이션으로 되돌리려면 `Header.module.css` 상단의
  `--header-bg` 한 줄만 주석 교체하면 된다


# 3. 디자인 토큰

`src/index.css` 의 `:root` 한 곳에서만 정의한다. 컴포넌트는 리터럴 색을 쓰지 않는다.

## 3.1 표면 · 잉크 · 선

| 토큰 | 라이트 | 용도 |
|---|---|---|
| `--plane` / `--plane-2` | `#eef4fb` / `#e5eef8` | 페이지 바탕 |
| `--panel` / `--panel-2` / `--panel-3` | `#ffffff` / `#f5f9fe` / `#e9f1fb` | 카드·헤더 내부·칩 |
| `--ink` / `--ink-2` / `--ink-3` | `#06203d` / `#2a4e73` / `#42648b` | 본문 / 보조 / 캡션 |
| `--line` / `--line-2` / `--track` | `#d5e2f2` / `#b6cbe3` / `#e0eaf6` | 경계선 / 진한 선 / 막대 트랙 |

다크 모드는 같은 이름으로 값만 교체한다.

## 3.2 건강 의미 색 (시리즈 색을 대체)

| 토큰 | 뜻 | 라이트 |
|---|---|---|
| `--ok` | 정상 범위 | `#0e8f7a` (청록) |
| `--warn` | 주의 구간 | `#b0700c` (호박) |
| `--alert` | 참고 범위 이탈 | `#c0432b` (적벽돌) |
| `--info` | 중립 데이터 | `#2f6ce0` (파랑) |

- 색만으로 상태를 전달하지 않는다. **아이콘·문구를 반드시 함께** 둔다 (색각 이상 대응)

## 3.3 BMI 구간 램프 (순서형 5+1단계)

저체중 → 비만 3단계까지 남색→하늘색→호박→적색 순서형 램프를 쓴다.
`--bmi-1` ~ `--bmi-6`.

## 3.4 강조색 (움직임 신호 전용)

- `--pulse: #e8541b` (다크 `#ff7a3d`)
- **데이터 값에 쓰지 않는다.** 게이지의 "현재 내 위치" 마커, 스윕 애니메이션,
  포커스 링에만 쓴다


# 4. 타이포그래피

| 항목 | 값 |
|---|---|
| 본문 폰트 | `Pretendard Variable` → Pretendard → Apple SD Gothic Neo → Noto Sans KR → 시스템 |
| 숫자·코드 | `--mono` (JetBrains Mono 계열), `font-variant-numeric: tabular-nums` |
| 기본 크기 | 16px / `line-height: 1.68` |
| 제목 | `clamp()` 로 반응형, `letter-spacing: -.03 ~ -.04em`, `font-weight: 800` |
| 큰 수치 | `clamp(38px, 6vw, 48px)`, `letter-spacing: -.055em`, weight 800 |
| 한글 줄바꿈 | `word-break: keep-all` + `overflow-wrap: anywhere` |

- Pretendard 는 참고 HTML 과 동일하게 jsDelivr CDN 의
  **dynamic-subset** 버전을 쓴다 (한글 폰트 용량 문제 회피)
- CDN 이 막힌 환경에서도 시스템 고딕으로 자연스럽게 대체된다


# 5. 모션 체계

## 5.1 원칙

- 모션은 **JS 가 켜졌을 때만** 적용한다 (`js-motion` 클래스). JS 실패 시 정적으로 다 보인다
- 화면에 들어올 때 한 번만 재생하고 관찰을 해제한다
- `prefers-reduced-motion: reduce` 면 전부 최종 상태로 즉시 표시한다
- 이징은 `--ease: cubic-bezier(.22,.72,.28,1)` 하나로 통일한다

## 5.2 목록

| 이름 | 동작 | 지속 |
|---|---|---|
| `reveal` | 아래에서 22px 올라오며 페이드인, 순차 지연 52ms | .40s |
| `bar-grow` | 막대 `width: 0 → var(--w)` | .52s |
| `count-up` | 숫자 0 → 목표값, easeOutCubic | .62s |
| `gauge-marker` | BMI 마커가 좌→우 자기 위치로 이동 + 살짝 튕김 | .70s |
| `sweep` | 게이지 위를 `--pulse` 선이 한 번 지나감 | .62s |
| `pop` | 카드 hover 시 3px 상승 + 그림자 강화 | .28s |

- 데스크톱 포인터(`hover:hover and pointer:fine`)에서만 hover 모션을 건다


# 6. 건강 결과 시각화

숫자 나열을 그래프로 바꾼다. 전부 애니메이션 대상이다.

| 컴포넌트 | 표현 | 쓰는 곳 |
|---|---|---|
| `BmiGauge` | 6구간 순서형 띠 + 내 위치 마커 | BMI |
| `RangeBar` | 참고범위 트랙 위 값 마커, 범위 밖이면 색 전환 | 체지방률, 혈액검사 6종 |
| `CompareBars` | 두 값을 같은 축에서 비교하는 가로 막대 | 현재체중 vs 표준체중, BMR vs TDEE |
| `GoalProgress` | 시작→목표 진행 막대 + 예상 기간 | 목표 체중 |

- 그래프에도 **수치를 텍스트로 반드시 병기**한다 (스크린리더·색각 이상 대응)
- `RangeBar` 는 값이 범위를 벗어난 방향(위/아래)을 마커 위치로 보여준다


# 7. 지켜야 할 것

- 컴포넌트 CSS 에 **리터럴 색을 쓰지 않는다.** 전부 토큰 참조
- 라이트·다크 **양쪽에서 대비를 확인**한다 (본문 4.5:1 이상)
- 모션은 **정보를 대체하지 않는다.** 모션이 꺼져도 모든 수치가 보여야 한다
- 의료 면책 문구는 디자인이 바뀌어도 계속 노출한다 (`CLAUDE.md` 5장)
